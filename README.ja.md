# cc-shiori（栞）

[English](README.md)

Claude Code の mod です。セッションごとに「栞」を挟みます。

- **どこまで来たか**: 目的・現状・あなた待ち・次・完了・決定
- **出てきた番号の中身**（索引）: チケット（`ABC-123`）・PR（`owner/repo#12`）・Issue・タスク（`T-012`）などが、そのセッションで何を指していたか

複数のセッションを並べて回していると、切り替えた先で「これは何をしていたセッションか」「`t-0005` って何だっけ」が分からなくなります。セッションの側は番号の中身を覚えていても、人間は忘れます。栞は、それを入力欄の上とサイドバーに出します。

> 「旅のしおり」が目的・行程・持ち物の一覧をまとめた冊子であるように、途中から戻ってきた人が、どこまで来て何を持っているかを分かるようにする道具です。

## 表示

**入力欄の上（帯）**: 目的と現状の2行。ターンの実行中は「(作業中)」、あなた待ちがあれば件数と「詳細」ボタン。

**サイドバー**（`/shiori` または「詳細」）:

| 項目 | 中身 |
|---|---|
| 目的 | セッション全体で何を達成しようとしているか |
| 現状 | 今どこまで来ているか |
| あなた待ち | Claude があなたの回答・判断・作業を待っていること |
| 次 | 次にやること |
| 索引 | 出てきた番号と、それが何を指すか（最後に話題になった順） |
| 完了・決定 | 最新 6 件ずつ |

## インストール

```text
/plugin marketplace add mitaku/cc-shiori
/plugin install shiori@cc-shiori
/reload-plugins
```

## 使い方

- 普段どおり会話すれば、本体のターンが終わるたびに栞が更新されます（ターンは待たせません）
- `/shiori` … サイドバーを開く
- `/shiori refresh` … 直近のターンから作り直す

言語は Claude Code の `language` 設定に従います（`Japanese` なら見出しも中身も日本語）。

## 仕組み

- 本体のターンが終わるたびに、**前回の栞と新しいターン**（依頼・最終回答・主なツール操作）だけを Haiku に渡して、栞を更新します。会話全体は送りません。ファイルの読み込みや検索の結果も送りません。
- 索引は「そのセッションが会話の中で理解している中身」です。モデルが書き落とした項目も消さず、新しく出てきたものや中身が変わったものほど上に来ます。
- 栞はセッションごとに mod のストア（`~/.claude/plugins/store/`）へ保存し、最新 200 件を残します。再開時は、最後のターンの栞があればそのまま出し、古ければ作り直します。`/clear` で新しく始めます。
- 非対話の実行（`claude -p`）やサブエージェントのターンでは動きません。

## 費用

本体のターンごとに Haiku を1回呼びます（セッションと同じアカウント・プロバイダ）。呼び出し回数はサイドバーの下に出ます。止めるときは `/plugin` で無効にしてください。

## 謝辞

[skanehira/claude-recap-plus](https://github.com/skanehira/claude-recap-plus) に着想を得ました。「セッションの要約を入力欄の上に出す」という形はそちらが先です。栞はそこに索引を足し、一から作り直したものです。
